About Our Project

ResHub is a Student Off-Campus Residence Review and Reporting System designed to help WSU students make informed decisions when choosing off-campus accommodation.

The system allows students to view residence information, read reviews from other students, rate residences, and report maintenance problems. This provides students with reliable information about residences before making accommodation decisions.

Objectives of the Project

  • Provide reliable information about off-campus residences.
  • Allow students to submit residence reviews and ratings.
  • Help students compare different residences.
  • Improve transparency about off-campus accommodation.
  • Allow administrators to manage reviews.

Main Features

  1. Student registration and login.
  2. WSU email verification.
  3. Residence information and search.
  4. Student reviews and ratings.
  5. Landlord ratings.
  6. Report status tracking.
  7. Administrator moderation.

Technologies Used

  • React JS - Used to develop the user interface.
  • CSS - Used for styling and responsive design.
  • Node.js - Used for backend development.
  • Supabase - Used for the database and authentication.
  • PostgreSQL - Used to store system data.
